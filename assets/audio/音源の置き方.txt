音源（BGM・効果音）の置き方
===========================

このフォルダに音源ファイルをそのまま入れてください。
入れたら data/audio.js の file に名前を書けば鳴ります。


■ 形式

  BGM   … mp3 または ogg
  効果音 … mp3 / ogg / wav（wav は短いものだけ。容量が大きい）

  ダウンロード形式がどれでも、上のどれかなら直さずに使えます。
  m4a や aac しか無い場合は、鳴らないブラウザがあるので mp3 に変換してください。

  ★ 入れていない音は、何も鳴らずにそのまま進みます（エラーにはなりません）。


■ 置いたあとにやること

  data/audio.js を開いて、file に名前を書きます。

    title: { file: null,        volume: 0.7 }
      ↓
    title: { file: "title.ogg", volume: 0.7 }

  volume は「その素材だけの音量」です（0〜1）。
  素材ごとに音の大きさが違うので、ここで揃えます。
  プレイヤーが変える音量（設定画面）とは別なので、混ぜないこと。

  技ごとの音は data/skills.js の se、状態異常ごとの音は data/statuses.js の se、
  仕掛け（宝箱・泉・罠）の音は data/features.js の se、
  当たった音（打撃／斬撃）は data/effects.js の hitSe から指します。


■ 忘れずに：クレジットと再配布

  フリー素材でも、サイトごとに条件が違います。使う前に必ず確認してください。

  1. クレジット表記が要るか
       要る場合は data/audio.js の credits に書きます。
       タイトル画面の左下と「遊び方」の「音楽・効果音について」に自動で並びます。

  2. 再配布して良いか  ← いちばん引っかかりやすい
       GitHub などにこのフォルダごと上げることは「再配布」にあたります。
       「素材の再配布禁止」と書かれている素材は、そのまま上げられません。

  3. 商用・非商用の別

  条件は素材サイトの規約が正です。ここに書いてあることではありません。

  いまの出どころは data/audio.js の credits と README の「素材のクレジット」を見てください。
