図鑑の説明文（data/monsters.js の description）

  主人公が書いた記録として書く（ストーリー構成.md の 2）。
  序盤の主人公はモンスターを恐れているので、警戒した事務的な書き方で揃える。
  形は「属性 → 見た目・生態 → 注意書き → 弱い属性」。

  ★ 「魔物」とは書かず「モンスター」で統一する。
  ★ 直したら data/monsters.js の description も同じ文にすること。
    （ゲームに出るのは data/monsters.js のほう。このファイルは読む・直すための控え）
  ★ 弱い属性は、実際の耐性（resistances のマイナス）に合わせてある。
    耐性を変えたときは、ここも見直す。
  ★ ただし**弱点をすべて書くとは限らない**。書いてあるのは「主人公が知っている弱点」。
    例：雷は使えるモンスターが少なく、主人公はまだ試せていないので、
        キングスライム（雷-3）やコウモリ（雷-2）の説明には雷の弱点を書いていない。
    この抜けは演出としてわざと残している。愛情度の記録（ストーリー構成.md の 10）で書き足せる。
  ★ 愛情度で書き足される記録（ストーリー構成.md の 10）は、その仕組みを作るときに足す。

坑道（苔むす坑道）
────────────────────────────────
スライム
 水属性。柔らかい体は打撃を吸い込み、傷もすぐに塞がる。見た目よりずっとしぶとい。動きは遅いが、人を襲う可能性はある。近づくときは注意すること。闇と雷に弱い。
  ※ 「人を襲う可能性はある」は物語の場面2でオルドが読み上げる（data/story.js の mineCleared）。変えるときはそちらも揃える

コウモリ
  闇属性。暗がりを好み、素早く飛び回る。気づいたときには背後にいる。明かりを絶やさないこと。火に弱い。

コケネズミ
  地属性。背に苔を生やした小型の獣。坑道の壁を走り回り、足元から来る。小さいからと油断しないこと。火に弱い。

イワゴロー
  地属性。岩が動いているとしか思えない。硬く、攻撃が通りにくいが移動は遅い。水に弱い。

ヒカリムシ
  光属性。尾を光らせて飛ぶ虫。暗い坑道では道しるべになるが、その光に別のモンスターが寄ってくるかもしれない。闇に弱い。

キノコン
  闇属性。坑道の湿った隅に生えるキノコのモンスター。近づくと胞子を撒く。光に弱い。

モスゴーレム
  地属性。探索者の間では坑道の主と呼ばれている。苔に覆われた石の巨人で、坑道の奥で長く眠っていたらしい。一撃が重い。光に弱い。

亀裂（灼熱の亀裂）
────────────────────────────────
スミビ
  火属性。燃えさしの炭が起き上がったもの。一体ずつは弱いが、群れで湧く。水に弱い。

フレイミン
  火属性。体に炎をまとう獣。気性が荒く近づくと牙をむく。水に弱い。

ハイバネ
  風属性。灰をまとって舞う鳥。亀裂の熱に乗って、上から来る。体は軽く脆い。水に弱い。

ヒビイワ
  地属性。熱でひび割れた岩のモンスター。守りは固いが、同じ石をぶつけると割れる。地に弱い。

マグマガニ
  火属性。マグマの中で暮らす中型のモンスター。殻を固めてじっと動かない。動かないからといって、背を向けないこと。水に弱い。

マグマウルフ
  火属性。探索者の間では亀裂の主と呼ばれている。たてがみが燃えていて、通った跡はすべて焦げている。近づくだけで肌が焼ける。火の息には注意。水に弱い。

深層（静寂の深層）
────────────────────────────────
ヨドミ
  闇属性。底に溜まった闇が形を持ったもの。一体では頼りないが、群れで湧く。光に弱い。

カゲヅタ
  闇属性。闇の底で根を張る蔦。絡みつかれると、少しずつ力を吸われる。足元に注意すること。火に弱い。

ミズダマリ
  水属性。底の水が集まって形を取ったもの。重い水の塊で叩き潰してくる。水たまりに見えても踏まないこと。雷に弱い。

ビリムシ
  雷属性。小さな体に電気をためこんだ虫。触れると弾ける。素手で触らないこと。地に弱い。

ヨミリュウ
  闇属性。揺籃の穴にいるはずのない竜。鱗は光を通さず吐く息は闇そのもの。勝てる相手とは思えない。見かけたら逃げること。光に弱い。

キングスライム
  水属性。探索者の間では深層の主と呼ばれている。スライムたちの王で、頭に冠を載せている。体が大きく、体重を生かしたボディプレスは強力。闇に弱い。

毒沼（腐食の毒沼）
────────────────────────────────
ドクバチ
  闇属性。毒沼の上を群れで飛ぶ蜂。刺された傷より、あとに残る毒のほうが長く効く。解毒草を持って入ること。光に弱い。

ドロガメ
  地属性。沼底の泥をかぶった亀。甲羅に溜めた泥から、たえず毒の息を漏らしている。風下に立たないこと。雷に弱い。

ヌマボネ
  闇属性。沼に沈んだ骨が、泥に浮いたまま動いている。眼窩の奥だけが青く光る。長く見ていたいものではない。光に弱い。

ヌシガエル
  水属性。探索者の間では沼の主と呼ばれている。動かずに口だけを開けて待ち、近づいたものを丸ごと呑む。間合いを測ってから近づくこと。雷に弱い。
